# Placement Support Dashboard - Website

## Overview

This is a static website for the Placement Updates Dashboard, designed to communicate the core problem and four commitments to students and stakeholders.

## File Structure

```
PlacementSite/
├── index.html          # Main homepage with complete styling
└── README.md          # This file
```

## Features

### Hero Section
- Clear headline: "Placement Support, Made Clear & Fair"
- One-liner value proposition
- Status badges showing live features
- Call-to-action buttons

### The Problem Section
Highlights the 4 key challenges students face:
1. **Unclear timelines** – No single view of events
2. **Scattered info** – Updates across multiple platforms
3. **Unequal support** – Inconsistent guidance
4. **High stress** – Pressure and comparison

### 4 Commitments Section

#### 1. Live Master Calendar
- Single source of truth for all placement events
- Filterable by support track
- See deadlines, recruiter visits, internal tasks

#### 2. 4 Support Tracks
- **Tier-1 prep**: High-rigor practice for competitive roles
- **Diverse careers**: Social sector, CSR, development, fellowships
- **Skill-building**: CV/CL labs, mock interviews, peer reviews
- **Personal support**: Doubt-clearing, 1-1 check-ins

#### 3. Weekly Updates
- Once-a-week snapshot of placement news
- New openings, deadlines, shortlists
- Weekly focus by support track

#### 4. Mental Health Support
- Real Talk circles on anxiety and rejection
- Safe spaces for non-linear journeys
- Celebrate all outcomes (jobs, higher studies, fellowships, experiments)

## Design

- **Dark theme** with green accent colors (#22c55e)
- **Responsive**: Mobile-first, works on all screen sizes
- **Performance**: All CSS embedded in single HTML file (no external dependencies)
- **Accessibility**: Semantic HTML, ARIA-friendly

## How to Use

### Local Development
1. Open `index.html` in any web browser
2. No build process or server needed

### Deploy to Web
- Host on GitHub Pages, Netlify, or any static hosting
- Single HTML file makes deployment trivial
